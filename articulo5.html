Responsive Design: Técnicas Avanzadas con CSS

20 de diciembre, 2023 • Por David López • 9 min de lectura

El responsive design ha evolucionado mucho desde los primeros media queries. Descubre técnicas avanzadas para crear experiencias verdaderamente adaptativas.

Media Queries Avanzadas

Además de width y height, podemos usar características avanzadas: 

/* Orientación del dispositivo */
@media (orientation: landscape) {
    .sidebar { display: block; }
}

/* Densidad de pixeles */
@media (-webkit-min-device-pixel-ratio: 2) {
    .logo { background-image: url('logo-2x.png'); }
}

/* Preferencias de usuario */
@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; }
}

/* Tema oscuro/claro */
@media (prefers-color-scheme: dark) {
    :root { --bg-color: #1a1a1a; }
}

Container Queries

Las container queries permiten que los componentes respondan a su contenedor, no solo al viewport: 

.card-container {
    container-type: inline-size;
}

@container (min-width: 400px) {
    .card {
        display: flex;
        gap: 1rem;
    }
    
    .card-image {
        flex: 0 0 150px;
    }
}

Unidades Responsivas

Viewport Units

  • vw, vh - Viewport width/height
  • vmin, vmax - Menor/mayor dimensión
  • svw, lvw, dvw - Small/Large/Dynamic

Container Units

  • cqw, cqh - Container width/height
  • cqi, cqb - Inline/Block size
  • cqmin, cqmax - Menor/mayor

Clamp() para Tipografía Fluida

La función clamp() permite crear tipografía que escala suavemente: 

/* Tipografía fluida */
h1 {
    font-size: clamp(2rem, 5vw, 4rem);
}

/* Espaciado fluido */
.container {
    padding: clamp(1rem, 5%, 3rem);
    gap: clamp(0.5rem, 2vw, 2rem);
}

Gríd Responsiva con CSS Grid

/* Grid auto-fit responsivo */
.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 2rem;
}

/* Grid con áreas nombradas */
.layout {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

@media (max-width: 768px) {
    .layout {
        grid-template-areas:
            "header"
            "main"
            "sidebar"
            "footer";
    }
}

Optimización de Imágenes Responsivas

<picture>
    <source media="(min-width: 800px)" srcset="hero-large.webp">
    <source media="(min-width: 400px)" srcset="hero-medium.webp">
    <img src="hero-small.webp" alt="Hero image" 
         loading="lazy" decoding="async">
</picture>

Mejores Prácticas

  • Diseña mobile-first siempre
  • Usa unidades relativas (rem, em, %)
  • Optimiza imágenes para diferentes dispositivos
  • Prueba en dispositivos reales, no solo simuladores
  • Considera la accesibilidad en todos los tamaños

El responsive design moderno va más allá de media queries básicas. Con estas técnicas avanzadas podrás crear experiencias verdaderamente adaptativas que funcionen perfectamente en cualquier dispositivo.
