Optimización de Performance en Aplicaciones Web

15 de diciembre, 2023 • Por Laura Fernández • 11 min de lectura

La performance web es crucial para la experiencia del usuario. Cada milisegundo cuenta: una página lenta puede significar pérdida de usuarios y conversiones.

Métricas Clave de Performance

Core Web Vitals

  • LCP: Largest Contentful Paint
  • FID: First Input Delay
  • CLS: Cumulative Layout Shift

Otras Métricas

  • FCP: First Contentful Paint
  • TTI: Time to Interactive
  • SI: Speed Index

Optimización de Imágenes

Las imágenes suelen ser el mayor contribuyente al peso de una página: 

/* Lazy loading nativo */
<img src="imagen.jpg" loading="lazy" alt="Descripción">

/* Formatos modernos */
<picture>
    <source srcset="imagen.webp" type="image/webp">
    <source srcset="imagen.avif" type="image/avif">
    <img src="imagen.jpg" alt="Fallback">
</picture>

/* Responsive images */
<img srcset="small.jpg 480w, medium.jpg 800w, large.jpg 1200w"
     sizes="(max-width: 480px) 100vw, (max-width: 800px) 50vw, 33vw"
     src="medium.jpg" alt="Imagen responsiva">

Code Splitting y Lazy Loading

Carga solo el código necesario cuando se necesita: 

// Dynamic imports
const loadModule = async () => {
    const module = await import('./heavy-module.js');
    return module.default;
};

// Intersection Observer para lazy loading
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            const img = entry.target;
            img.src = img.dataset.src;
            observer.unobserve(img);
        }
    });
});

document.querySelectorAll('img[data-src]')
    .forEach(img => observer.observe(img));

Compresión y Minificación

Gzip/Brotli

Comprime archivos de texto hasta 90% menos tamaño.

Minificación

Elimina espacios, comentarios y caracteres innecesarios.

Tree Shaking

Elimina código JavaScript no utilizado.

Caching Estratégico

/* Service Worker para caching */
self.addEventListener('fetch', event => {
    if (event.request.destination === 'image') {
        event.respondWith(
            caches.match(event.request).then(response => {
                return response || fetch(event.request).then(fetchResponse => {
                    const responseClone = fetchResponse.clone();
                    caches.open('images-v1').then(cache => {
                        cache.put(event.request, responseClone);
                    });
                    return fetchResponse;
                });
            })
        );
    }
});

Optimización del Critical Path

  • Inline CSS crítico en el HTML
  • Defer o async para scripts no críticos
  • Preload recursos importantes
  • Prefetch recursos para páginas futuras
<!-- Preload fuentes importantes -->
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>

<!-- Async para scripts no críticos -->
<script src="analytics.js" async></script>

<!-- Defer para scripts que necesitan el DOM -->
<script src="main.js" defer></script>

<!-- Prefetch para páginas probables -->
<link rel="prefetch" href="/about.html">

Lista de Verificación

  • ☑️ Optimizar imágenes (formato, tamaño, lazy loading)
  • ☑️ Minificar y comprimir CSS/JS
  • ☑️ Implementar caching apropiado
  • ☑️ Reducir requests HTTP
  • ☑️ Usar CDN para assets estáticos
  • ☑️ Optimizar fuentes web
  • ☑️ Monitorear Core Web Vitals

La optimización de performance es un proceso continuo. Mide, optimiza, y vuelve a medir. Cada mejora, por pequeña que sea, contribuye a una mejor experiencia de usuario.
