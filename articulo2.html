JavaScript Moderno: ES6+ y las Nuevas Características

10 de enero, 2024 • Por María González • 8 min de lectura

JavaScript ha evolucionado enormemente desde ES6 (2015). Las nuevas características han transformado la forma en que escribimos código, haciéndolo más limpio, legible y eficiente.

Arrow Functions

Las arrow functions proporcionan una sintaxis más concisa para escribir funciones y manejan el contexto `this` de manera diferente: 

// Función tradicional
function suma(a, b) {
    return a + b;
}

// Arrow function
const suma = (a, b) => a + b;

// Con un solo parámetro
const doble = x => x * 2;

// Sin parámetros
const saludo = () => "¡Hola mundo!";

Destructuring

El destructuring permite extraer valores de arrays u objetos de forma elegante: 

// Destructuring de objetos
const usuario = { nombre: 'Ana', edad: 25, ciudad: 'Madrid' };
const { nombre, edad } = usuario;

// Destructuring de arrays
const colores = ['rojo', 'verde', 'azul'];
const [primero, segundo] = colores;

// Con valores por defecto
const { altura = 170 } = usuario;

Template Literals

Los template literals facilitan la interpolación de strings y permiten strings multilínea: 

const nombre = 'Carlos';
const edad = 30;

// Template literal
const mensaje = `Hola, soy ${nombre} y tengo ${edad} años.`;

// Multilínea
const html = `
    <div>
        <h1>${nombre}</h1>
        <p>Edad: ${edad}</p>
    </div>
`;

Async/Await

Async/await hace que el código asíncrono sea más fácil de leer y escribir: 

// Con Promises
function obtenerDatos() {
    return fetch('/api/datos')
        .then(response => response.json())
        .then(data => console.log(data))
        .catch(error => console.error(error));
}

// Con async/await
async function obtenerDatos() {
    try {
        const response = await fetch('/api/datos');
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error(error);
    }
}

Módulos ES6

Los módulos permiten organizar el código en archivos separados: 

// math.js
export const PI = 3.14159;
export function suma(a, b) {
    return a + b;
}
export default function multiplicar(a, b) {
    return a * b;
}

// main.js
import multiplicar, { PI, suma } from './math.js';
// o
import * as math from './math.js';

Spread Operator

El operador spread (...) permite expandir elementos de arrays u objetos: 

// Con arrays
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const combinado = [...arr1, ...arr2]; // [1, 2, 3, 4, 5, 6]

// Con objetos
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };
const combinado = { ...obj1, ...obj2 }; // { a: 1, b: 2, c: 3, d: 4 }

// Copiar arrays/objetos
const copia = [...original];
const copiaObj = { ...original };

Nuevos Métodos de Array

ES6+ introdujo varios métodos útiles para trabajar con arrays: 

const numeros = [1, 2, 3, 4, 5];

// find() - encuentra el primer elemento que cumple la condición
const mayor3 = numeros.find(n => n > 3); // 4

// includes() - verifica si un elemento existe
const tieneEl3 = numeros.includes(3); // true

// flatMap() - mapea y aplana en una operación
const duplicados = numeros.flatMap(n => [n, n * 2]);
// [1, 2, 2, 4, 3, 6, 4, 8, 5, 10]

Conclusión

Las características modernas de JavaScript han revolucionado el desarrollo web. Adoptar estas nuevas sintaxis y funcionalidades te permitirá escribir código más limpio, mantenible y eficiente.

No es necesario aprender todo de una vez. Comienza incorporando una característica a la vez en tu código diario y gradualmente irás dominando JavaScript moderno.
